# Mockingword（ブラウザー拡張）

Webページ、選択した文章、入力したテキストを、ブラウザーの中だけで訳す拡張機能です（既定は日本語へ訳す。訳文の言語は設定で53言語から選べる）。PLaMo 3 Translateをwllama（llama.cppのWASM版）で動かします。翻訳する文章や訳文を作者・翻訳サービスへ送信しません。

Android版 [Mockingword](https://github.com/kagerouttepaso/PlamoTranslate) と同じ名前・アイコンを使う、非公式の個人開発ソフトウェアです。Preferred Networksとは関係ありません。

## できること

- ページの本文を訳し、訳文・原文・対訳を切り替える。リンクとインラインコードを保つ。
- 選択した文章を鳥のアイコンから吹き出しで訳す。右クリックからも使える。
- PDFを、レイアウト・リンク・しおりを残したまま訳す（訳文の言語は画面で選ぶ。最初は設定の訳文の言語。右から左へ書く言語など一部の言語は選べない）。画面で読みながら、見ているページから訳文に替わり、訳したPDFを保存できる。ブラウザーで開いたPDFでは「このPDFを訳す」、手元のファイルはツールバーのメニューの「PDFファイルを開いて訳す」から使う。文章を選んで右クリックの「選択範囲を…に訳す」で、テキスト翻訳の画面に訳を出すこともできる。
- テキスト翻訳の画面で文章を入力して訳す。日本語のほか52言語へも訳せる。
- WebGPUが使えればGPU、読み込めなければCPUで動く。
- 0.8B（既定、約573MB）・2B（約1.81GB）のモデルを選べる。モデルは初回利用時に公式Hugging Face配布元から取得する。

## インストール

[Chromeウェブストア](https://chromewebstore.google.com/detail/ncpkibiacmcngnnfeglekhnpbefdijmp)から入れられます（Chrome・Brave・Edgeなど）。開発版を試す場合：

1. このリポジトリを取得する。
2. `chrome://extensions`（Braveでは`brave://extensions`）で「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの`extension`を選ぶ。
4. ツールバーでMockingwordを開き「このページを訳す」を押す。初回はモデル取得を待つ。

通常のHTTP/HTTPSページを対象にします。ブラウザーの設定ページ、ストアなど拡張機能の実行が制限されたページでは使えません。翻訳速度と必要メモリーは端末によって異なります。訳文の正確さは保証しません。

設定の「画面の色」から、端末に合わせる・ライト（さえずりの紙）・ダーク（夜の鳥）を選べます。テキスト翻訳の「貼り付け」は、クリップボードの文字を選択位置へ入れます。

## 使い方と保存する情報

ページ翻訳は`Alt+T`、またはツールバー・右クリックのメニューから開始します。同じタブで同じサイトの別ページへ移ると翻訳を続け、原文へ戻す・翻訳をやめる・別サイトへ移ると終了します。

原文と訳文のキャッシュは拡張機能の領域に保存します。設定の「翻訳のキャッシュ」から削除できます。調査ログは既定で無効です。有効にすると本文の一部や閲覧先を含むため、書き出す際は内容を確認してください。通信・設定同期・削除方法は [プライバシーポリシー](PRIVACY.md) を参照してください。

## 開発

Node.js 24以上。`npm test`で単体試験を実行します。ブラウザーでの試験、申請ZIPの作成、WASMの再ビルドは [開発手順](docs/DEVELOPMENT.md)。設計の入口は [アーキテクチャ](docs/02_アーキテクチャ.md)、現在地は [docs/00_現在地.md](docs/00_現在地.md)。
