# 現在地

更新日：2026-11-25

Mockingword 1.2.1。Webページ・選択した文章・入力したテキスト・PDFを、ブラウザーの中だけで PLaMo 3 Translate（既定 0.8B）を使って訳す Manifest V3 拡張。訳文の言語は既定で日本語、設定で53言語から選べる（PDF は34言語）。翻訳する文章を外部へ送らない。Chromeウェブストアで公開している（1.0.0から）。

この文書は今の状態と文書の地図だけを書く。版ごとの変更と理由・検証は [変更履歴](変更履歴.md)。

## 利用者の報告と未解決

- 既存のBraveで右上の拡張メニューが開かない、未翻訳でも完了と出るとの報告がある。通常の新規プロファイルではメニュー表示を確認できたが、作者の環境での原因は確認できていない。未翻訳ページの追加調査は作者の判断で中止した。0.9.1でこれらを修正したとは扱わない。
- 製品の既知の制約・未対応は [リスクと未決事項](07_リスクと未決事項.md)。
