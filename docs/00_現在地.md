# 現在地

更新日：2026-11-22

Mockingword 0.13.0。ブラウザー内で動くPLaMo 3 Translate翻訳拡張。既存実装0.8.7を独立した公開用リポジトリへ移した初版から続く。

## 0.13.0の変更

- 最初のバッチ（見出しと第1段落）の返事を待たずに、画面内の残りの段落を空いている同時実行の枠へ送る。最初のバッチを待つ間、枠の一部しか使わず画面内の段落が待たされていた。代償として、計算の遅いGPUでは最初の訳文が遅れうる。設計は [ページの翻訳](04_ページの翻訳.md)。
- 長い段落は、まとめて1回で訳したまま、生成の途中で訳し終わった文から表示する。訳文の文の数だけ原文の文を先頭から置き換え、残りの原文は薄く残す。最後の返事で書式付きの訳文に置き換え、キャッシュには最後の返事だけを入れる。原文と訳文の文の対応は近似で、途中は1文ほどずれることがある（作者の判断：段落の訳の質を保ったまま、最初の1文から読めるようにする）。
- 横並びの一覧の項目（`li`・`dt`・`dd`）を、表示がインラインでも1件ずつ別の段落として扱う。一覧全体を1つの段落にまとめていたため、項目ごとにCSSで描く区切りの中点や入れ子の括弧が訳した後に消えていた。短い項目は送るときに今までどおりまとめて訳す。
- ページ翻訳の使い心地の計測（`tools/page-replay.mjs --ux`）を加えた。分母は計測側が翻訳前のDOMから数え、網羅は「訳文が原文から変わったか」でなく、翻訳の処理を通って確定した訳文が反映されたかで判定する。指標は「画面内に訳文が出始めるまで」「画面内で最も遅い段落の、最初の1文が読めるまで」など。定義は [ページ翻訳のUX計測](13_ページ翻訳のUX計測.md)。
- 検証：`npm test` 24件合格。保存したページで1回ずつ、最初のバッチの返事より前に画面内の別のバッチが送られること、段落の第1文と薄い原文の途中表示から訳文だけへの置き換え、一覧の区切りと括弧が残ること、パンくずの項目とリンク先が崩れないことを確かめた。性能の計測は未実施。

## 0.12.0の変更

- PDFを、レイアウト・リンク・しおりを残したまま日本語にする PDF翻訳のページ（`ui/pdf.html`）を加えた。入口は内蔵ビューアで開いたPDFの `Alt+T`・ツールバーのメニュー「このPDFを訳す」・範囲を選ばずに右クリックした「このPDFを日本語に訳す」と、ツールバーのメニューの「PDFファイルを開いて訳す」（手元のファイル）。設計は [PDFの翻訳](12_PDFの翻訳.md)。
  - 品質の基準は「日本語で読めること」を最優先にし、原文のレイアウトへの忠実さより優先する（作者の判断。Androidの画面翻訳と同じ位置づけ）。
  - 画面に出す訳したPDFと保存するPDFは同じもの（作者の要件）。訳したPDFは Worker で PDFium が1つ書き、ページの段落がそろうたびにそのページを差し替える。訳している段落は半透明にする。
  - 表示は pdf.js のビューア。見ているページから訳し、拡大縮小・見開き・原文と訳文の切り替え・見出しの欄（しおり）・戻る・進む・翻訳の中止と再開を備える。Webページへのリンクは新しいタブで開く。
  - 手元のPDF（`file://`）は、拡張機能の詳細で「ファイルのURLへのアクセスを許可」をオンにすると同じ操作で訳せる（`file:///*` の権限を追加。作者の承認）。編集などを制限して暗号化したPDFは暗号化を保ったまま訳す（しおりは原文のまま。作者の了承）。
  - PDFium（WASM）・pdf.js・pdf-lib・harfbuzz（hb-subset）を `vendor/` に同梱した。日本語フォント（Noto Sans JP、約11MB）は初めて使うときに jsDelivr から取得し、SHA-256 を確かめて Cache Storage に置く。PRIVACY.md・拡張内のプライバシーポリシー・ライセンス表示・store/申請情報.md を更新した。
  - `pdf/` の層を加え、`tools/architecture.test.mjs` と [設計方針](11_設計方針.md)「層」を同じ変更で直した。
- テキスト翻訳で訳文の言語を日本語と52言語から選べ、「⇄」で原文と訳文の言語を入れ替えられるようにした（Androidアプリのテキスト翻訳と同じ。作者の依頼）。文体は日本語へ訳すときだけ出す。訳文のキャッシュの鍵に訳文の言語を足したので、それより前のキャッシュは使われない。
- 試験用のブラウザーの起動（`tools/lib/browser.mjs`）に、隠れた窓の描画とタイマーを止めない設定を足した。窓がほかの窓の後ろに隠れると pdf.js がページを描き終えず、試験の結果が画面の使い方に左右された。
- 検証（試験用のBrave、新しいプロファイル、0.8B）：
  - Kvaser Leaf v3 M12 User's Guide（20ページ）を通しで訳し、1ページ目が約12秒で訳文に替わり、全体は約95〜105秒だった。途中の拡大縮小・見開き、全ページを通して見て戻る、原文・訳文の切り替え、日本語の選択、訳したページのリンクで移って戻る、保存したPDF（1.17MB → 1.46MB、本文としおりが日本語）を確かめた。画面の絵と保存したPDFの絵の画素の違いは、原文同士を同じ方法で比べた差と同じ程度だった。
  - 300ページ・18MB の試験用のPDFを、すぐに訳文を返す偽の翻訳で通し、全体71秒、画面の長い処理（50ミリ秒以上）0回だった。
  - 偽の翻訳で、リンクが行ごとの範囲で1つになること、戻る1回で元の位置へ戻ること、Webページへのリンクが新しいタブで開くこと、翻訳の中止と再開、訳している途中に別のPDFを開くことを確かめた。
  - テキスト翻訳で、日本語・英語・韓国語・中国語（簡体字）へ訳せることを確かめた。
  - `npm test` と通し試験（`tools/e2e.mjs`）の結果は [公開前確認](../store/公開前確認.md)。

## 0.9.3の変更

- PDF（ブラウザーの内蔵ビューアで表示する文書）で、選んだ文章を訳せるようにした。右クリックのメニューは「選択範囲を日本語に訳す」1項目にして拡張機能の名前の下にまとめず、訳はテキスト翻訳の画面に出す。`Alt+T` はテキスト翻訳を開き、ツールバーのメニューは案内を出す。仕組みは [アーキテクチャ](02_アーキテクチャ.md)「内蔵ビューアで表示する文書」。
- Brave の自動試験で、PDFのタブを内蔵ビューアの文書と判定すること、HTMLのタブは従来どおりであること、`Alt+T` 相当の操作でテキスト翻訳が開くことを確かめた。通し試験36項目に合格（Brave）。作者の確認で、ほかの項目を `visible: false` で隠すだけでは拡張機能の名前の下にまとめられたため、取り除く形に直した。直した後、PDFでは項目がメニューの1段目に出ることを作者がBraveで確認した。PDFから複数行を選んでも訳が行ごとに途切れないことも作者が確認した。訳を出す先はテキスト翻訳のタブのままにする（作者の判断）。

## 0.9.2の変更

- 段落の中の要素（太字・斜体・リンク・コード・`<br>`・アイコンなど）を、種類を名指しせず1つの規則でマーカーにして訳文へ写し直し、原文側は段落の中身ごと隠す。GitHub の Issue で太字が消える、改行・ログの行がつながる、訳文表示で訳文の上に空行が並ぶ、を直した（作者の報告、2026-11-16）。インラインコードの空の箱の対処（`data-plamo-shell`）も同じ流れに置き換えた。
- 段落の流れを層に分けた：範囲（`page/collect.js`）、中身の読み取りと要素の分類（`page/paragraph.js`）、マーカーの文法（`shared/markup.js`）、書き込み（`page/write.js`）。設計の決まりを [設計方針](11_設計方針.md) にまとめ、`npm test` で層の依存・正本の一意性を検査する。
- 計測ツールが名前の変更（0.9.0）の後、ページのログを拾えなくなっていたのを直した（ログの頭を `shared/messages.js` の `LOG_TAG` に一本化）。
- 独自の呼び名を、開発文書・コメントでは一般の技術用語（キャッシュ、Service Worker、Offscreen Document、バッチ、マーカーなど）に、画面・プライバシーポリシー・README・ストア掲載文では一般的な名称に置き換えた。使わない言い換えの表は [設計方針](11_設計方針.md)「用語」で、`npm test` が検査する。要件に優先順位（外へ出さない＞誤訳しない＞レイアウトを崩さない＞読みやすい訳語＞速さ）と訳語の方針を明記した（[要件](01_要件.md)）。
- 通し試験36項目に合格（Brave）。性能は計測条件の安定しない時間の参考値で、前の版と同程度（`store/公開前確認.md`）。
- バッジ（MDN の「Read only」など、角の丸い小さな枠の表示）も枠の見た目ごと訳文に残す。バッジだけの行が英語のまま返っても訳し直さない（日本語の文書でも Read only のままが読みやすい、作者の判断）。文の途中の `<br>`（小文字で続く行）は空白にして文をつなぐ。理由と計測は [ページの翻訳](04_ページの翻訳.md)「マーカー」。

## 0.9.1の変更

- 小さいアイコンはAndroidの印と同じ中央72格子から描画し、ストア用の余白を除いた。16・32・48pxは絵の外形がキャンバスいっぱいに収まる。
- 設定・メニュー・テキスト翻訳・タブのタイトル・ツールバーのヒントに読み込み中の版を表示する。
- 通常ボタン、文字操作、入力フォーカスの色をAndroidの共通部品の役割へそろえた。個別のTextタイルとの色合わせは行わない。
- 利用者へ渡した版を同じ番号で差し替えず、manifestとpackage.jsonの版を一致させる。
