# 現在地

更新日：2026-11-15

Mockingword 0.9.0。ブラウザー内で動くPLaMo 3 Translate翻訳拡張。既存実装0.8.7を独立した公開用リポジトリへ移した初版。

## この版の変更

- 表示名をMockingwordへ変更し、Android版の鳥のアイコンと「夜の鳥／さえずりの紙」の色・部品の役割を共用する。
- 個人環境の記述と実測結果の生データを公開対象から除外し、新しい履歴で開始する。
- HTTP/HTTPSのページを対象とし、重複するactiveTab権限を削除する。
- プライバシーポリシー、第三者ライセンス、拡張内の説明と導線、申請用ZIPの作成手順を追加する。
- 設定からライト・ダーク・端末に合わせるを選べ、テキスト翻訳に貼り付けボタンを追加した。
- Chrome for Testing・Braveを`BROWSER`で指定できるようにする。

## 申請準備

掲載文、権限説明、データ取扱い、審査者用の再現手順は [申請情報](../store/申請情報.md)。検証の結果は [公開前確認](../store/公開前確認.md) に記録する。

申請送信は作者の文面レビューを待つ。ストア申請・公開はまだ実施していない。

## 設計・固定した版

設計はdocs/01〜05、WASMの固定入力と採用パッチは [vendor README](../extension/vendor/wllama/README.md) と`tools/wllama/pins.json`。翻訳モデルのURL・サイズは`extension/offscreen/offscreen.js`。技術的な実験・判断の記録はdocs/08〜10を参照する。
