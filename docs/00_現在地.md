# 現在地

更新日：2026-11-16

Mockingword 0.9.2。ブラウザー内で動くPLaMo 3 Translate翻訳拡張。既存実装0.8.7を独立した公開用リポジトリへ移した初版。

## 0.9.2の変更

- 段落の中の要素（太字・斜体・リンク・コード・`<br>`・アイコンなど）を、種類を名指しせず1つの規則で目印にして訳文へ写し直し、原文側は段落の中身ごと隠す。GitHub の Issue で太字が消える、改行・ログの行がつながる、訳文表示で訳文の上に空行が並ぶ、を直した（作者の報告、2026-11-16）。インラインコードの空の箱の対処（`data-plamo-shell`）も同じ流れに置き換えた。
- 段落の流れを層に分けた：範囲（`page/collect.js`）、中身の読み取りと要素の分類（`page/paragraph.js`）、目印の文法（`shared/markup.js`）、書き込み（`page/write.js`）。設計の決まりを [設計方針](11_設計方針.md) にまとめ、`npm test` で層の依存・正本の一意性を検査する。
- 計測ツールが名前の変更（0.9.0）の後、ページのログを拾えなくなっていたのを直した（ログの頭を `shared/messages.js` の `LOG_TAG` に一本化）。
- 通し試験36項目に合格（Brave）。性能は日中に測った参考値で前の版と同程度（`store/公開前確認.md`）。作者が指定する時間に測り直す。
- バッジ（MDN の「Read only」など、角の丸い小さな枠の表示）も枠の見た目ごと訳文に残す。バッジだけの行が英語のまま返っても訳し直さない（日本語の文書でも Read only のままが読みやすい、作者の判断）。文の途中の `<br>`（小文字で続く行）は空白にして文をつなぐ。理由と計測は [ページの翻訳](04_ページの翻訳.md)「目印」。

## 0.9.1の変更

- 小さいアイコンはAndroidの印と同じ中央72格子から描画し、ストア用の余白を除いた。16・32・48pxは絵の外形がキャンバスいっぱいに収まる。
- 設定・メニュー・テキスト翻訳・タブのタイトル・ツールバーのヒントに読み込み中の版を表示する。
- 通常ボタン、文字操作、入力フォーカスの色をAndroidの共通部品の役割へそろえた。個別のTextタイルとの色合わせは行わない。
- 利用者へ渡した版を同じ番号で差し替えず、manifestとpackage.jsonの版を一致させる。

## 利用者の報告と未解決

既存のBraveで右上の拡張メニューが開かない、未翻訳でも完了と出るとの報告がある。通常の新規プロファイルではメニュー表示を確認できたが、本人の環境での原因は確認できていない。未翻訳ページの追加調査は本人の指示で中止した。0.9.1でこれらを修正したとは扱わない。2026-11-15、本人が外観・掲載文を了承し、申請を進めるよう指示した。

## 独立公開時（0.9.0）の変更

- 表示名をMockingwordへ変更し、Android版の鳥のアイコンと「夜の鳥／さえずりの紙」の色・部品の役割を共用する。
- 個人環境の記述と実測結果の生データを公開対象から除外し、新しい履歴で開始する。
- HTTP/HTTPSのページを対象とし、重複するactiveTab権限を削除する。
- プライバシーポリシー、第三者ライセンス、拡張内の説明と導線、申請用ZIPの作成手順を追加する。
- 設定からライト・ダーク・端末に合わせるを選べ、テキスト翻訳に貼り付けボタンを追加した。
- Chrome for Testing・Braveを`BROWSER`で指定できるようにする。
