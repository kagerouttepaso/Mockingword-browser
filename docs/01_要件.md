# 要件

更新日：2026-11-09

## 目的

作者が Brave で読む外国語のページや文章を、PCの中だけで日本語に訳す。文章を外部の翻訳サービスへ送らない。仕事の画面（GitHub の組織設定など）も、そのまま読める速さで訳す。

## 共通の前提

- **ブラウザーの中だけで動く**。翻訳サーバーや追加のソフトを入れない。モデルは初回に Hugging Face から取得し、拡張機能の中に保存する（2026-11-09、作者の判断で翻訳サーバー版をやめた）。
- **原文の言語**：PLaMo 3 Translate が扱う53言語のうち、日本語を除く52言語。既定は自動判定。訳す先は日本語だけ。
- **モデル**：0.8B（既定。速い）と 2B（訳が正確、約3倍遅い）を選べる。
- **動作モード**：自動（WebGPU が使えれば GPU、だめなら CPU）・GPU・CPU。CPU はスレッド数を選べる。
- **PCに合わせる調整**：同時に訳す本数・ubatch・スレッド数をPCごとに変えられ、同期しない。設定画面の「このPCに合わせる」で測って一番速い値を選べる（2026-11-09、作者の依頼）。
- **メモリー**：使わない時間が続いたら（既定10分）モデルを解放する。手でもすぐ解放できる。
- **文章を外へ出さない**：ページの文字は、拡張機能の中（裏方・見えないページ）にだけ渡す。調査用のログもブラウザーの中だけに置く。

## ページの翻訳

- ツールバーのボタンのメニュー、`Alt+T`、右クリックの「このページを日本語に訳す」で、ページ全体を訳す。
- 画面に見えている段落から先に訳す。後から読み込まれた段落、書き換わった段落も訳す。
- 訳文・原文・対訳（原文の下に訳文）を、訳しているページの上部のバーで切り替える。バーには進み具合を出す。
- バーの ×、ボタンのメニューの「翻訳をやめて元のページに戻す」で、訳文を消して元のページに戻す。
- 段落の中のリンクは、訳文の中でも押せるまま残す。インラインコードは原文のまま残す。
- 訳さないもの：日本語の段落、コードのブロック、入力欄、`translate="no"`、SVG・MathML の中、CSS・JavaScript のような文。
- 訳したタブで同じサイトの別のページへ移ったら、移動先も同じ表示で自動で訳す。
- 一度訳した文は控え、同じ文はモデルを使わずにすぐ置き換える。

## 段落・選択範囲

- 範囲を選ばずに右クリックしたときのメニューは「このページを日本語に訳す」だけ。段落だけ訳すときは範囲を選ぶ（2026-11-09、作者の指示）。
- 文章を選んで右クリック →「選択範囲を日本語に訳す」：選択範囲の訳を吹き出しで出す。
- 文章を選んで右クリック →「選択した段落を日本語に訳す」：選択にかかる段落を訳文に置き換える。
- 文章を選ぶと、選択範囲の右下に「訳」アイコンがふわっと出る。押すと吹き出しで訳す（設定でオフにできる）。
- 吹き出しから、選んだ文章を入れたテキスト翻訳のページを開ける。

## テキスト翻訳

- Google 翻訳のような、左に入れて右に訳が出るページ。入力が止まったら訳す。
- 原文の言語（自動か52言語）と文体（です・ます／だ・である）を選べる。
- 言語の混ざった文章も、行ごとに訳す。

## 調べやすさ

- 設定の「調査用のログ」をオンにすると、ページ・裏方・モデルの出来事を時刻付きで残し、JSON で保存できる。
- 遅い・止まるときに、何を待っているかを上部のバーで見られる（送信中の本数と最長の待ち時間）。

## 性能の目標

- 画面に見えている部分は数秒で訳し終える（GitHub の組織設定ページで2.5秒）。
- 1度訳したページは、読み直してもすぐ訳文になる（控え）。
- 訳していないときは、GPU を使い続けない。使わない時間が続いたらメモリーを返す。

## 範囲外

- 日本語以外への翻訳。
- 翻訳サーバー（ネイティブの llama-server）を使う構成。0.3.0 までの Git の履歴に残っている。
- Chrome Web Store への公開。今は「パッケージ化されていない拡張機能」として読み込む。
