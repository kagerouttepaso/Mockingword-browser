# 要件

更新日：2026-11-16

## 目的

外国語のページや文章を、PCの中だけで日本語に訳すブラウザー拡張機能。文章を外部の翻訳サービスへ送らない。作者が仕事で読む画面（GitHub の Issue・組織設定、MDN などの技術文書）を、構造を保ったまま、読める速さで訳す。Chromeウェブストアで一般に公開する。

## 優先順位

要件どうしがぶつかったときは、上を優先する。下の項目のために上の項目を損なう変更は、作者の判断なしに入れない。

1. **文章を外へ出さない**：ページの文字は拡張機能の中（Service Worker・Offscreen Document）にだけ渡す。調査用のログもブラウザーの中だけに置く。
2. **誤訳しない**：原文の意味を変えない。別の段落の訳を付けない、訳し漏れを訳し終わったように見せない。
3. **レイアウトを崩さない**：段落の中のリンク・太字・改行・コード・バッジ・画像を訳文でも保つ。訳文表示で原文の残り（空の箱・空行）を出さない。
4. **読みやすい訳語**：下の「訳語の方針」に従う。
5. **速さ**：画面に見えている部分から先に、数秒で訳す。1〜4を保つための手間（構造を運ぶマーカー、訳し直し）は必要なコストとして受け入れ、速さのために構造や訳を落とさない（2026-11-16、作者の判断）。

## 訳語の方針

- コード（インラインコード・API 名）は原文のまま残す。
- バッジ（MDN の「Read only」「Secure context」、GitHub のラベルのような、角の丸い小さな枠の表示）は、枠の見た目を保つ。文字は、モデルが英語のまま返したらそのまま使い、訳し直さない。日本語の文書でも Read only のままのほうが読みやすい（2026-11-16、作者の判断）。
- 見出し・文章は、文脈に合った自然な日本語にする（例：設定画面の見出しの「General」は「概要」）。短い英字の見出しが英語のまま残ることがある（未対応。`docs/07`）。
- 製品名・モデル名・ボタン名のような短い英字の項目は、英語のまま返ったものを受け入れる。

## 文言の方針

- 画面・プライバシーポリシー・ストア掲載文は、技術者でない人にも通じる一般的な名称を使う（キャッシュなど）。独自の呼び名を作らない。
- 開発文書・コメントは、一般の技術用語とコードの識別子で書く（[アーキテクチャ](02_アーキテクチャ.md)「用語」、[設計方針](11_設計方針.md)）。

## 動く環境

- **ブラウザーの中だけで動く**。翻訳サーバーや追加のソフトを入れない。モデルは初回に Hugging Face から取得し、拡張機能の中に保存する（2026-11-09、作者の判断で翻訳サーバー版をやめた）。
- **原文の言語**：PLaMo 3 Translate が扱う53言語のうち、日本語を除く52言語。既定は自動判定。訳す先は日本語だけ。
- **モデル**：0.8B（既定。速い）と 2B（訳が正確、約3倍遅い）を選べる。
- **動作モード**：自動（WebGPU が使えれば GPU、だめなら CPU）・GPU・CPU。CPU はスレッド数を選べる。
- **PCに合わせる調整**：同時実行数・ubatch・スレッド数をPCごとに変えられ、同期しない。設定画面の「このPCに合わせる」で測って一番速い値を選べる（2026-11-09、作者の依頼）。
- **メモリー**：使わない時間が続いたら（既定10分）モデルを解放する。手でもすぐ解放できる。

## ページの翻訳

- ツールバーのボタンのメニュー、`Alt+T`、右クリックの「このページを日本語に訳す」で、ページ全体を訳す。
- 画面に見えている段落から先に訳す。後から読み込まれた段落、書き換わった段落も訳す。
- 訳文・原文・対訳（原文の下に訳文）を、訳しているページの上部のバーで切り替える。バーには進み具合を出す。
- バーの ×、ボタンのメニューの「翻訳をやめて元のページに戻す」で、訳文を消して元のページに戻す。
- 段落の中のリンクは、訳文の中でも押せるまま残す。
- メニュー・ナビ・表の見出しのような短い項目は、同じグループの項目をまとめて訳し、周りの項目を文脈にする（`docs/04`「短い項目のグループ」）。
- 訳さないもの：日本語の段落、コードのブロック、入力欄、`translate="no"`、SVG・MathML の中、CSS・JavaScript のような文。
- 訳したタブで同じサイトの別のページへ移ったら、移動先も同じ表示で自動で訳す。
- 一度訳した文はキャッシュに入れ、同じ文はモデルを使わずにすぐ置き換える。

## 段落・選択範囲

- 範囲を選ばずに右クリックしたときのメニューは「このページを日本語に訳す」だけ。段落だけ訳すときは範囲を選ぶ（2026-11-09、作者の指示）。
- 文章を選んで右クリック →「選択範囲を日本語に訳す」：選択範囲の訳を吹き出しで出す。
- 文章を選んで右クリック →「選択した段落を日本語に訳す」：選択にかかる段落を訳文に置き換える。
- PDF など、ブラウザーが内蔵ビューアで表示する文書では、右クリックのメニューを「選択範囲を日本語に訳す」1項目にし（拡張機能の名前の下にまとめない）、選んだ文章をテキスト翻訳で訳す。ページ全体・段落の翻訳はできない（2026-11-16、作者の希望）。訳はテキスト翻訳のタブに出す。ツールバーのメニューや小さな別ウィンドウに出す案もあったが、別タブのままにした（2026-11-16、作者の判断）。
- 文章を選ぶと、選択範囲の右下に「訳」アイコンがふわっと出る。押すと吹き出しで訳す（設定でオフにできる）。
- 吹き出しから、選んだ文章を入れたテキスト翻訳のページを開ける。

## テキスト翻訳

- Google 翻訳のような、左に入れて右に訳が出るページ。入力が止まったら訳す。
- 原文の言語（自動か、日本語を含む53言語）と訳文の言語（日本語か52言語。既定は日本語）を選べる。日本語へ訳すときは文体（です・ます／だ・である）も選べる。「⇄」で原文と訳文の言語を入れ替えられる（原文の言語が自動のときは使えない）。Androidアプリのテキスト翻訳と同じ（2026-11-17、作者の依頼）。ページ・選択範囲・PDFの翻訳は日本語へ訳す。
- 言語の混ざった文章も、行ごとに訳す。

## 調べやすさ

- 設定の「調査用のログ」をオンにすると、ページ・Service Worker・モデルの出来事を時刻付きで残し、JSON で保存できる。
- 遅い・止まるときに、何を待っているかを上部のバーで見られる（送信中のバッチ数と最長の待ち時間）。

## 性能の目標

- 画面に見えている部分は数秒で訳し終える（GitHub の組織設定ページで2.5秒）。
- 1度訳したページは、読み直してもすぐ訳文になる（キャッシュ）。
- 訳していないときは、GPU を使い続けない。使わない時間が続いたらメモリーを返す。
- 性能の計測は、作者がPCを使っていない時間に、変更を固めてから1回だけ行う（AGENTS.md）。

## 範囲外

- 日本語以外への翻訳。
- 翻訳サーバー（ネイティブの llama-server）を使う構成。0.3.0 までの Git の履歴に残っている。
