# 選択範囲とテキスト翻訳

更新日：2026-11-09

選択範囲の「訳」アイコンと吹き出し、選択した段落の翻訳、テキスト翻訳のページ。

## 操作

| 操作 | 動き | 受け持ち |
| --- | --- | --- |
| 文章を選ぶ →「訳」アイコンを押す | 選択範囲の訳を吹き出しで出す | `page/watch.js` → 裏方 → `page/bubble.js` |
| 文章を選んで右クリック →「選択範囲を日本語に訳す」 | 同上 | `background/menus.js` → `page/bubble.js` |
| 文章を選んで右クリック →「選択した段落を日本語に訳す」 | 選択にかかる段落を訳文に置き換える | `page/main.js` の `translateSelectedParagraphs` |
| 吹き出しの「テキスト翻訳で開く」 | 選んだ文章を入れてテキスト翻訳のページを開く | 裏方の `openTextPage` |
| ボタンのメニュー「テキスト翻訳を開く」 | テキスト翻訳のページを開く | 同上 |

文章を選んで右クリックしたときはメニューの項目が2つになるので、ブラウザーが拡張機能の名前「PLaMo翻訳（ローカル）」の下にまとめる。項目名に「（PLaMo）」は付けない（2026-11-09、作者の指摘）。範囲を選ばずに右クリックしたときは「このページを日本語に訳す」だけを出す（段落だけ訳すときは範囲を選ぶ。2026-11-09、作者の指示で「この段落を日本語に訳す」をやめた）。

## 「訳」アイコン

`page/watch.js`（すべてのページ・すべての枠に入る通常のスクリプト）。Google 翻訳の拡張機能のように、文章を選び終えたら選択範囲の最後の行の右下に、青い丸の「訳」アイコンを浮かび上がらせる（透明・少し下から、0.16〜0.18秒）。

- 出すとき：マウスを離したとき（左ボタン）、Shift を使ったキー操作の後。選択が確定するのを0.01秒待ってから見る。
- 出さないとき：設定でオフ、選択が空、日本語（かな）を含む、文字が無い、5000字を超える、入力欄・編集できる要素・拡張機能自身の要素の中。
- 消すとき：ほかの場所を押す、選択が外れる、スクロール、`Esc`、ウィンドウを離れる。
- 押したとき：mousedown の既定の動きを止めて選択を保ち、`selection-icon` を裏方へ送る。裏方はその枠へページ側を差し込み、`translate-selection` を送る。
- 選んだだけでは文を裏方へ送らない。押したときだけ送る。
- アイコンは閉じた Shadow DOM の中に作る（ページの CSS の影響を受けない）。

## 吹き出し

`page/bubble.js` の `translateSelection`。選択範囲のすぐ下に出し、`translate-one` の返事で中身を書き換える。下に訳したモデルと秒数、「テキスト翻訳で開く」を出す。`Esc` か外側のクリックで閉じる。モデルの準備の進み具合は、ページを訳していれば上部のバー、そうでなければ右下に出す。

## 選択した段落

`page/main.js` の `translateSelectedParagraphs`。選択範囲にかかる文字のノードから段落（ブロック要素）までさかのぼり、重ねずに並べる（`page/collect.js` の `blocksInRange`。親子の両方が入ったら親だけ）。その段落の並びを `translateBlocks` に渡し、ページ全体の翻訳と同じ仕組み（集める→控え→送り出し→書き込み）で訳す。ページ全体は訳さない。後でバーの「ページ全体を訳す」で残りを訳せる。置き換えた後は、訳文が選択の色で見えにくくならないよう、選択を外す。
- 既に集めた段落（訳した・訳を待っている）なら、表示を訳文にするだけにする。訳す文章が無ければ右下に知らせる。

## テキスト翻訳のページ

`ui/translate.html`・`ui/translate.js`。

- 左に文章を入れ、入力が0.8秒止まったら右に訳す。`Ctrl+Enter`・「翻訳」ですぐ訳す。同じ入力・言語・文体なら訳し直さない。古い依頼の返事は捨てる。
- 原文の言語（自動か52言語）はこのページだけの選択（ページの翻訳には効かない）。文体は設定と共有する。
- 下書きと原文の言語は、このページの localStorage に残す（タブを閉じても戻せる）。
- 行ごとに訳す（`translate-one` に `lines: true`。`core/translator.js` の `translateLines`）。1つの問い合わせに言語を混ぜると、2言語目以降の行を原文のまま返すことがあるため。
- 訳し終わるのを待たずに出す：`translate-one` に `stream`（番号）を渡すと、裏方が訳文の途中と生成したトークン数を0.1秒おきに `text-partial` で送る。まだ訳していない行は空にして、訳し始めた行から出す。下の欄に「翻訳中… 〇トークン・〇 tok/s」、訳し終えたら「PLaMo 0.8B・〇秒・〇トークン・〇 tok/s」。速さは最初のトークンからの時間で割る（モデルの読み込みを入れない）。経路は、見えないページが `stream` の問い合わせだけ行の区切りを待たずに途中を送り（`offscreen.js`）、`core/engine.js` の `complete` が `onPartial`・`onTokens` へ渡し、`translator.js` が行・片の途中をつなぐ。
- 広さ：広い画面では左右いっぱいに近く使う（最大 2400px）。欄は窓の高さから始め、入力欄は `field-sizing: content` で入れた文章の長さに合わせて伸びる。貼り付けた時点で原文全体が見え、両方の欄が同じ高さまで伸びるので、ページをスクロールして原文と訳文を並べて読める（2026-11-12、作者の依頼。以前は幅1200pxで余白が大きく、入力欄は訳し終わるまで伸びなかった）。
- 吹き出しから開いたときは、裏方が文章を `storage.session` の `pendingText` に置き（URL に載せない）、ページを開くか、開いていれば `take-text` を送る。ページは受け取ったら消す。
