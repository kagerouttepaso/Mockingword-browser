# リスクと未決事項

更新日：2026-11-10

## リスクと備え

| リスク | 起きると | 備え |
| --- | --- | --- |
| モデルが止まらなくなる（同じ語句の繰り返し・行の出しすぎ） | 「訳しています」のまま GPU を使い続ける | 逐次受け取りで打ち切る（`docs/03`「生成の打ち切り」）。生成の上限も低めにした |
| 文章でない長い文字列（CSS・JavaScript・データ）を訳しに行く | モデルが写し続けて、ほかの段落が待たされる。繰り返しではないので打ち切れない | 段落の集め方で除く（SVG・MathML の中、`{ } ;` の多い文）。新しい種類が見つかったら、調査用のログで特定して `page/collect.js`・`shared/text.js` に足す |
| ページが訳すたびに書き換える | 訳し直しが止まらない | 同じ段落の訳し直しは3回まで |
| ドラッグなどで中身が次々に変わる | もう無い文の翻訳が枠を埋める | 書き換えが0.7秒落ち着いてから訳す。消えた段落の問い合わせは取り消す |
| ページの CSP がモジュールの読み込みを止める | ページ側が動かない | CSP を付けた試験ページで確かめている（`tools/e2e.mjs`）。止まるサイトが見つかったら、`page/` を1ファイルにまとめる手順を考える |
| Hugging Face のファイルが差し替わる | 照合が合わない・訳が変わる | コミットを固定した URL で取る |
| wllama・Brave の更新で WebGPU の動きが変わる | 読み込めない・遅くなる | 自動のモードは GPU で読み込めなければ CPU で読み込み直す。版を上げるときは `tools/e2e.mjs` と `tools/bench.mjs` を回す |
| 0.8B の取り違え（固有名詞・口語） | 訳が不正確 | 2B に切り替えられる。訳したページで切り替えると訳し直す |
| ブラウザー内の遅さ | 長いページで待たされる | 見えている順と控えに加え、自前ビルドの採用パッチを組み込む。通常版の時間と内訳を分け、性能の採否は `docs/09` へ残す |
| 自前ビルドの JS・WASM の組み合わせ違い | 読み込めない・採用した改善が効かない | 同じ build manifest の成果物を一緒に差し替え、SHA-256 とパッチ順序を vendor の README に記録する。profile・profile-gpu の計測版は同梱しない |
| 8本で文脈長・KV容量が増える | GPU で読めず CPU へ切り替わる、ほかの処理のメモリーを圧迫する | 1本あたりの文脈長を保つと容量が増える（`docs/03`）。既定は8本（2026-11-10）。検証環境B（Radeon 860M）での読み込みと速さは未確認 |
| sampling の指定だけを配布版へ加える | token-only の読み戻し削減・argmax の修正が効かない | `backend_sampling_token_only` は自前パッチで追加する項目。配布版では無視されるため、採用パッチを含む通常版の差し替えと通しの試験を一組にする |

## 決まっていないこと

- **2B を既定にするか**：訳の質は 2B が良いが約3倍遅い。作者が日常で使って決める。
- **同じサイト内の自動翻訳の範囲**：登録ドメインの近似で判定している。別会社の子ドメインが混ざるサイトで困ったら見直す。
- **控えの上限**：2万件。足りない・多すぎると分かったら変える。
- **自動調整で最初の訳の速さをどう扱うか**：`tune.js` の GPU 候補は既に8本を含み、全体の時間が基準より十分に短ければ8本を保存する。最初のまとまりまでの時間は表に残すが、選択の条件には入っていない。既定は8本（2026-11-10、作者の判断）。自動調整は全体の時間で4本など少ない本数を選びうる。見えている訳を先に出す要件に合わせて選択条件や開始時の本数を変える案は、作者の採否を得てから実装する。
- **自動モードの調整中に CPU へ切り替わった候補の扱い**：コード上、最初の読み込みで GPU と判定した後でも、8本などメモリーを多く使う候補だけ CPU へ切り替わる経路がある。各行には実際の `device` を残すが、比較は全体時間で続ける。GPU の候補として採否を出す場合は動作モードを GPU に固定して測る。自動調整から動作モードが変わった行を除く案は、追加の変更として提案中。
- **自前ビルドの最終成果物の反映**：採用済みは commands・sampling・matmul（0001）・result・prefill・matmul-h8（0002＋0003）。attention（H5）は修正・再計測中。ビルド基盤の採否から、最終パッチの順序・通常版の差し替え・通しの試験を確定する段階へ進んだ。内蔵GPU・2Bへの適用は実機で確認する。

## バックログ（使って不満が出たら）

- ページの文脈（前後の段落）をプロンプトの `context` に入れて、訳を安定させる（Android の会話翻訳と同じ考え方）。
- 訳文の表示の細かい調整（対訳の色・行間）。
- サイトごとの「訳さない」設定。
