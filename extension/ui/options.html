Mockingword設定

翻訳はすべてブラウザーの中（WebGPU か CPU）で行い、ページの文章は外へ出ません。モデルは初回だけ Hugging Face から取得して、拡張機能の中に保存します。

画面の色
翻訳モデル ボタンのメニューからも切り替えられます。訳したページで切り替えると、新しいモデルで訳し直します。
このPCの性能に合わせる この欄の設定はPCごとに保存し、ほかのPCへ同期しません（内蔵GPUのPCと単体GPUのPCで合う値が違うため）。 変えると、読み込んでいるモデルを解放し、次に訳すときに新しい設定で読み込みます。
「このPCに合わせる」を押すと、設定を変えながら同じ文章を訳して時間を比べ、いちばん速い設定を保存します（今のモデルで1〜4分。測っている間はPCを操作しないでください。0.8Bと2Bで合う値が違うので、モデルを替えたら合わせ直してください）。
設定試験用の文章24件を訳す時間（キャッシュなし）最初の1件生成の速さ

細かい調整


ページの翻訳で、同時にモデルへ送る文章のまとめの数です。GPU の性能に余裕があるほど、多くすると全体が速くなります。多すぎると1件ずつが遅くなり、画面内が出るまでが延びます。

原文を読み込むときに GPU へまとめて渡すトークン数です。単体GPUでは大きくすると速くなることがあり、内蔵GPUではメモリーを多く使うだけのことがあります。

このPCは論理コア 個です。CPU で動かすとき（自動で CPU になったときを含む）に使います。

翻訳のキャッシュは、一度訳した文と訳文の組です。同じ文はモデルを使わずすぐ出します。最大2万件で、超えると古く使ったものから消します。
訳文の文体
ページの翻訳：原文の言語
既定の「自動」では、PLaMoが扱う52言語（日本語を除く）を段落ごとにモデルが判定して訳します。 自動で訳が崩れるページだけ、言語を決めてください。テキスト翻訳の言語は、そのページで選びます。
選択範囲の翻訳 日本語（かな）を含む選択や、入力欄の中の選択には出しません。右クリックの「選択範囲を日本語に訳す」はこの設定によらず使えます。
ページの翻訳：訳したときの表示 Alt+T（またはボタンのメニューの「このページを訳す」）をもう一度押すと原文に戻り、さらに押すとこの表示に戻ります。
調査用のログ 翻訳が遅い・止まるときにオンにして同じ操作をし、「ログを保存」したファイルを確認してください。記録はこのブラウザーの中だけにあり、 ブラウザーを閉じるか拡張機能を読み込み直すと消えます。ページの文は先頭60字だけを残します。
