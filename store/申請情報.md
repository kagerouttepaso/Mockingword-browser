## 短い説明

Webページ・選択した文章・入力したテキストを、ブラウザー内のAIで日本語に翻訳します。翻訳内容を外部サーバーへ送信しません。

## 詳細説明

Mockingwordは、Webページや文章をブラウザーの中で日本語に訳す翻訳拡張です。翻訳モデルPLaMo 3 Translateを端末上で動かし、翻訳する文章や訳文を作者・外部の翻訳サービスへ送信しません。

【主な機能】
・ページ全体の翻訳と、原文・訳文・対訳の切り替え（見えている所から訳し、長い段落も訳し終えた文から順に表示）
・選択した文章の吹き出し翻訳、右クリックからの翻訳
・PDFをレイアウト・リンク・しおりを残したまま日本語にし、訳したPDFを保存（ブラウザーで開いたPDF・手元のPDF。見ているページから訳し、訳し終えた文から順に表示）
・クリップボードから貼り付けた文章や入力した文章を訳すテキスト翻訳画面（日本語のほか52言語へも訳せます）
・WebGPU対応端末ではGPU、読み込めなければCPUで動作
・0.8Bと2Bのモデル切り替え
・一度訳した文章をブラウザー内にキャッシュし、再表示を高速化

【はじめに知っておいてほしいこと】
初めて翻訳するときに約573MBのモデルをHugging Faceからダウンロードします。2Bモデルを選ぶ場合は約1.81GBです。ダウンロードには通信が必要ですが、取得後の翻訳は端末内で行います。ページ翻訳で日本語フォントの切り替えを有効にしているときは、使った系統の日本語フォントを初回だけjsDelivr（Fontsource）からダウンロードしてブラウザー内にキャッシュします（設定でオフにできます）。PDF翻訳を初めて使うときは、訳文を書く日本語フォント（約11MB）をjsDelivrからダウンロードします。速度・必要メモリーは端末によって異なります。

通常のWebページが対象です。Chromeの設定ページ、Chromeウェブストアなど、拡張機能の実行が制限されたページでは使えません。翻訳の正確さは保証しません。

原文・訳文のキャッシュとテキスト翻訳の下書きはブラウザー内に残ります。設定からキャッシュを消去でき、下書きはテキスト翻訳の「消す」で消去できます。調査ログは既定で無効です。有効にした場合は本文の一部や閲覧先を含むため、書き出した内容を確認してから共有してください。

## 単一の目的

利用者が指定したWebページ・選択範囲・入力テキストを、ブラウザー内の翻訳モデルで日本語へ翻訳すること。

## 権限の理由

| 権限 | 申請画面へ入力する説明 |
| --- | --- |
| scripting | 利用者が翻訳を開始したページに、原文の収集・訳文の表示・原文への復元を行うスクリプトとCSSを挿入します。 |
| contextMenus | ページや選択範囲を右クリックから翻訳するメニューを提供します。 |
| storage | モデル・文体・表示などの設定、PCごとの性能設定、同じタブ・サイト内で翻訳を継続する一時状態を保存します。 |
| offscreen | 見えない拡張ページで、同梱のWASMとダウンロード済みモデルを使って端末内推論を継続します。 |
| unlimitedStorage | 約573MB・約1.81GBの翻訳モデルと原文・訳文のキャッシュを拡張機能の保存領域に保持します。 |
| alarms | 一定時間使わなかった翻訳モデルをメモリーから解放するため、定期的に未使用時間を確認します。 |
| http://*/*、https://*/* | 任意のWebページの本文・選択範囲を翻訳し、選択時の翻訳アイコンを表示します。利用者が翻訳を開始したタブでは同じサイト内の移動先も翻訳します。ページに常駐する監視は、この継続翻訳と選択翻訳を提供するためです。閲覧先を作者へ送信する機能はありません。モデル取得先へのアクセスにも使います。 |
| file:///* | 利用者がブラウザーで「ファイルのURLへのアクセスを許可」をオンにしたときだけ、手元で開いたPDF・ページを、Webページと同じ操作で端末内翻訳します。ファイルの内容を外部へ送信しません。 |

任意のサイトで選択翻訳と同一サイト内の移動後の翻訳を提供するため、activeTabのみでは機能が完結しません。HTTP/HTTPSと、利用者が許可したときだけ有効になるfile://以外のサイトアクセスは要求しません。

## リモートコード

「No, I am not using remote code.」を選択します。実行するJavaScriptとWASMはZIPに同梱しています。外部から取得するGGUFは翻訳モデルの重みデータです。コードを取得してevalする機能はありません。

## データの取扱い

ローカル処理だけでも扱うデータを開示します。申請画面のデータ分類では「Website content」（本文・選択範囲・入力文章）と「Web history」（同一サイト内の継続翻訳に使う閲覧先・サイトの識別）を申告します。作者への送信・広告・解析・売却はありません。任意の調査ログには処理の情報と本文の一部・閲覧先が含まれます。

データを第三者へ販売しないこと、拡張の単一目的と無関係な用途に利用・転送しないこと、信用評価や融資判断に利用・転送しないことを申告します。ダウンロード配信に伴う通信とブラウザーの設定同期はPRIVACY.mdに説明しています。

## 審査者用の手順

申請画面の「追加の手順」は500文字までなので、次の文をそのまま入力します。

1. 認証・アカウント・APIキーは不要です。通常の英語Webページを開きます。
2. ツールバーのMockingwordで「このページを訳す」を押します。初回は約573MBのモデルを取得します。
3. 「原文」「対訳」「翻訳をやめて元のページに戻す」を確認します。
4. 英文を選択し、鳥のボタンまたは右クリックで訳します。
5. 「テキスト翻訳を開く」で英文を入力または貼り付けて訳します。
6. 設定で画面の色、モデル、動作モード、キャッシュの消去、プライバシー・ライセンスを確認します。
7. 英語のPDFを開き、ツールバーの「このPDFを訳す」または右クリックの「このPDFを日本語に訳す」で、訳したPDFを表示・保存します。初回は約11MBの日本語フォントを取得します。

GPUで読み込めない場合はCPUへ切り替わります。CPU翻訳や初回の準備には時間がかかる場合があります。掲載画像は新しいプロファイルと架空の文章で実際の拡張を動かして撮影したものです。
